# Modern Improvement Ideas

## Already Implemented
- PWA icons and install prompt.
- Mobile bottom navigation.
- Pull-to-refresh on Events and Channels.

## Suggested Enhancements
- Smarter search suggestions for events and channels.
- Favorites and recently watched streams.
- Offline-friendly caching for API responses.
- Accessibility audit (contrast, focus states, ARIA).

## Quick Wins
- Provide a compact "copy link" toast on mobile.
- Add a "clear filters" button for Events.

## Longer-Term Ideas
- Multi-stream view (2-4 players).
- Personalized homepage based on viewing history.
- Optional push notifications for event start times.
